# Chapter 21 — Playtest Checklist

Unity mein Play button dabane ke baad, ye sab cheezein baari-baari test kar
lein. Jo sahi kaam kare us par ✅ laga lein, jo na kare uska note bana lein
aur mujhe bata dein.

## Basic Flow
- [ ] Game khulte hi sahi player ("Red's Turn" waghera) dikhta hai
- [ ] Roll button dabane par dice ghumta hai aur ek number (1-6) dikhata hai
- [ ] Sahi token select ho kar move hota hai (hop karte hue)
- [ ] Move mukammal hone ke baad agla player ki baari aati hai

## Yard Se Nikalna
- [ ] Dice par 6 na aaye tou yard ka token move nahi hota (Roll dobara chal sakta hai)
- [ ] Dice par 6 aaye tou token yard se bahar nikalta hai
- [ ] 6 aane par usi player ko **dobara** roll karne ka mauka milta hai

## Capture (Katna)
- [ ] Apna token dushman ke token wale cell par jaye tou dushman ka token yard wapas chala jata hai
- [ ] Safe (star) cells par capture NAHI hota — dono tokens saath khaRe reh sakte hain
- [ ] Apne hi rang ke 2 tokens ek dusre ko capture nahi karte

## Home Stretch Aur Jeet
- [ ] Token poora chakkar laga kar apne rang ke home-stretch mein muRta hai
- [ ] Exact number na aaye tou token home mein nahi ghusta (aage nahi baRhta)
- [ ] Jab token ke saare 4 tokens finish ho jayein, "Wins!" screen aati hai
- [ ] Restart button dabane se naya match shuru hota hai

## Teen Chhakke Ka Rule
- [ ] Lagatar 3 baar 6 aane par baari khud cancel ho jati hai, agle player ko milti hai

## Settings & Audio (agar laga chuke hon)
- [ ] Settings button dabane se panel khulta hai
- [ ] Volume slider/mute toggle se awaz kam-zyada hoti hai
- [ ] Game band kar ke dobara kholne par settings yaad rehti hain

## AI (agar AIPlayer laga hai)
- [ ] Computer wale rang ki baari khud-ba-khud chal jati hai (dice + move)
