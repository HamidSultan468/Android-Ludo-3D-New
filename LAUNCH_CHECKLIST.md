# Chapter 25 — Final Launch Checklist

Publish karne se pehle ye sab check kar lein.

## Technical
- [ ] `PLAYTEST_CHECKLIST.md` ke saare items pass ho chuke hain
- [ ] Development Build **OFF** hai (Build Settings mein untick karein — final
      build mein ye ON nahi honi chahiye, warna app slow aur bari hogi)
- [ ] App ka version number set hai (Player Settings → Version)
- [ ] Keystore file mehfooz jagah save hai (backup bhi bana lein — kho jane
      par app kabhi update nahi ho sakegi)

## Store Listing
- [ ] `PLAY_STORE_LISTING.md` wala text Play Console mein daal diya
- [ ] Icon (512x512), Feature Graphic (1024x500), aur kam se kam 2 screenshots upload ho chuke hain
- [ ] Privacy Policy URL daal diya
- [ ] Content Rating questionnaire mukammal ho chuka hai

## Google Play Console Account
- [ ] Developer account bana hua hai (one-time $25 registration fee lagti hai)
- [ ] App ka naya "App" entry Play Console mein bana diya
- [ ] `.aab` file (Android App Bundle) upload kar di

## Final Review
- [ ] Ek aakhri baar poora match khud khel kar dekh liya (start se jeet tak)
- [ ] Sab text/labels sahi hain, koi ghalti wali spelling nahi

---
Sab tick ho jaye tou **"Submit for review"** dabayein. Google ka review
aam tor par kuch ghanton se 1-2 din tak lag sakta hai. Approve hote hi app
Play Store par live ho jayegi. 🎉

Mubarak ho — ye ek mukammal Android Ludo 3D game hai!
